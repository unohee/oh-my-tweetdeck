## Oh My TweetDeck 0.1.1

TweetDeck-style macOS app: X / Threads / Instagram web columns plus one composer that cross-posts.

**Requires** macOS 14+ (Apple Silicon).

### Changes since 0.1.0
- The signing and notarization pipeline that produced the 0.1.0 download is now part of the repository (0.1.0 was signed from an uncommitted script). Release builds are signed with a Developer ID Application certificate, with the hardened runtime and a secure timestamp, plus explicit entitlements. They are notarized by Apple with the ticket stapled, so Gatekeeper opens the app without a warning, even offline.
- `scripts/build-app.sh` signs with Developer ID when `OMT_SIGN_ID` is set (`auto` picks the identity from the keychain). Without it, it signs ad-hoc for local development. `scripts/notarize.sh` notarizes, staples and writes the release zip and checksum.
- `scripts/release.sh` publishes a release in one repeatable step. It never replaces an existing release or asset. `scripts/verify-release.sh` checks a published release from its public download: checksum, signature, hardened runtime, notarization ticket, Gatekeeper and version.
- The README shows the app logo and has an Install section and signing/release docs.

### Install
1. Download `OhMyTweetDeck-0.1.1-macos.zip` and unzip it.
2. Move `OhMyTweetDeck.app` to Applications and open it.

Verify the download with the attached checksum:

```bash
shasum -a 256 -c OhMyTweetDeck-0.1.1-macos.zip.sha256
```
